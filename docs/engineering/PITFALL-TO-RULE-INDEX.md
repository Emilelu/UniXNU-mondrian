## 反查表：按现象找铁则

| 你遇到的现象 | 看这条铁则 |
|---|---|
| 改了补丁但构建没变化 | **★14**（真相源是 SERIES-FINAL.txt，三处都要改）|
| `git apply` 报 corrupt patch / new blank line / does not apply | **★15**（三个硬性格式要求）|
| 功能实现了但不执行 | **★16**（查默认值 / arg 拼写 / #if 包裹 / 双门控）|
| 写入 MMIO 无效 / data abort / 整机挂死 | **★17**（窗口够大 / 虚拟地址 / 判空）|
| 硬件协议读不出数据 | **★18**（反编译控制器层 / 同型号核对引脚时钟）|
| 日志里没有某驱动输出 | **★19**（≠没运行，要拿可复现命令+原始输出）|
| 改了 init.c 没效果 / 重编 init 后 panic | **★20**（先问是否非它不可；ldid-lite；-sectcreate）|
| subagent 跑完零产出 | **★21**（单窗口可完成 + 必须产出文件）|
| push 卡住 / 读到旧代码 | **★22**（Windows 侧 push；fetch 后要 pull）|
| 又在从零实现某功能 | **★23**（先查 zizhan / LOCAL-ASSETS / TOOLBOX）|
| 想让文件出现在设备上 | **★26**（先查 build.py 的 data_seed / var.skel / 离线 dd）|
| 改 build 脚本后整层不链接 | **★24**（先 diff -u 黄金脚本）|
| 编译通过但运行炸 | **★25**（要运行时可观测判据）|
