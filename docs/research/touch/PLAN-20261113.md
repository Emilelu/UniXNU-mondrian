2. identification failure 有明确原因并能继续至轮询后，新增真实且有界的 `Pong touch: POLL hb int=… polls=… reports=… touches=… bad=…` 心跳（例如每 64 次轮询一行）；这是进入阶段三输入验收的前置任务，不是可选优化。INT 上升或读次数增加不得记为 `reports`；同时保证连续报告的 raw 与 normalized 坐标可审计。

4. 在可通信/供电证据成立后重采原始 BRL 帧，只有当前读数复现偏移才改解析；保持 Mode 0、已验证 GPIO（MISO 17 / MOSI 18 / CLK 16 / CS 19 / RESET 20）、333 kHz。
5. 每次修改重建冻结清单，走 strict 构建/校验/归一启动流程。
